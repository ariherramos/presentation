Projetos

Decisor de janela aberta

Python Flet APP Android

Projeto pessoal desenvolvido como um aplicativo em Python com Flet para analisar condições ambientais e responder a uma dúvida muito real: vale a pena deixar a janela aberta quando passamos longas horas fora de casa? Em cidades litorâneas, com alta umidade e a necessidade de ventilação da casa, essa decisão impacta diretamente o conforto, a qualidade do ar e o ambiente interno.

Dinamômetro de motor

C C++ Qt

Projeto universitário desenvolvido em 2017 para construir um dinamômetro de motor com foco na medição de torque, rotação e comportamento sob carga. O sistema utilizou um microcontrolador ATmega328P para adquirir dados dos sensores e uma interface gráfica em Qt em C++ para visualizar e registrar os resultados dos testes.

Build limpo para múltiplas plataformas

C CMake STM32

Projeto que visa apresentar conceitos e boas práticas para compilar dois projetos embarcados por meio do CMake, usando C para as famílias STM32C0 e STM32G0. A ideia é reutilizar a arquitetura comum, compartilhar módulos de forma organizada e manter a compilação modular, com maior legibilidade e facilidade de manutenção entre diferentes microcontroladores.

Benchmark GCC vs Clang

C CMake Docker GCC Clang STM32

Este repositório apresenta um ambiente em Docker para compilar o mesmo projeto embarcado em STM32 com GCC e Clang, permitindo comparar comportamento dos compiladores, qualidade do código gerado e desempenho da build em um cenário controlado. O foco é avaliar trade-offs práticos entre as ferramentas e documentar um fluxo de benchmark mais organizado para desenvolvimento embarcado.
