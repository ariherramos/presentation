Window open decision helper

Python Flet APP Android

A personal project developed as a Python app with Flet to analyze environmental conditions and answer a very real question: is it worth leaving the window open when we spend long hours away from home? In coastal cities, with high humidity and the need for natural ventilation, this decision directly affects comfort, air quality, and the indoor environment.

Motor Dynamometer

C C++ Qt

University project developed in 2017 to build a motor dynamometer for measuring torque, rotation speed, and load behavior. The system used an ATmega328P microcontroller to acquire data from sensors and a Qt-based desktop interface in C++ to visualize results and manage data acquisition during testing.
